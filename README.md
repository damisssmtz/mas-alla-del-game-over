# Más allá del Game Over | Jugar también es interpretar

> **Medio digital independiente dedicado a interpretar los videojuegos como expresiones culturales.**
> Divulgación humanística, análisis narrativo y crítica social.

## 🎮 Prototipo (DEMO)
Este repositorio contiene el prototipo funcional e interactivo del portal web desarrollado para la Actividad Integradora de la Licenciatura en Humanidades y Narrativas Multimedia.

- **Autor:** Edgar Damián Martínez Vázquez
- **DEMO en vivo:** [https://damisssmtz.github.io/mas-alla-del-game-over/](https://damisssmtz.github.io/mas-alla-del-game-over/)

## 🚀 Tecnologías
- HTML5 semántico
- Tailwind CSS (vía CDN)
- Google Fonts (Plus Jakarta Sans & JetBrains Mono)
- JavaScript interactivo nativo
